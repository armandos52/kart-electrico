# Cómo aportar comentarios y mejoras

Gracias por revisar el proyecto. No es necesario instalar Obsidian para consultar la documentación ni para dejar comentarios en GitHub.

Para esta entrega, empezar por el [dossier del 13-10-2026](00_INICIO/REVISION_PARA_PROFESORES.md). Citar la etiqueta `revision-academica-2026-10-13` permite conservar el contexto aunque avance el desarrollo.

## Elegir dónde comentar

- [Discussions](https://github.com/armandos52/kart-electrico/discussions): preguntas generales, alternativas de diseño e ideas que necesitan debate.
- [Nueva observación](https://github.com/armandos52/kart-electrico/issues/new/choose): un error, una duda técnica localizada o una mejora con un resultado concreto.
- [Pull requests](https://github.com/armandos52/kart-electrico/pulls): revisar o proponer modificaciones de archivos. Los comentarios sobre líneas se realizan en la vista de cambios de una pull request.

Se necesita una cuenta de GitHub para publicar comentarios. No hace falta permiso de escritura para participar en las conversaciones públicas. Las propuestas de cambios se revisan antes de integrarlas.

## Información útil para una revisión

1. Enlace al documento y página, hoja o sección.
2. Versión del documento o enlace al commit si la observación depende de una versión concreta.
3. Configuración del kart afectada, si se conoce.
4. Observación, razonamiento y, si existe, fuente de apoyo.
5. Cambio o comprobación que se propone realizar.

Para un PDF, indicar la página del visor y aclarar si difiere de la numeración impresa. Diferenciar un dato medido de una hipótesis o recomendación.

## Seguimiento

Una observación aceptada se vinculará a una tarea o cambio documental. Su resolución deberá explicar qué se modificó y qué evidencia lo respalda. Las conclusiones técnicas se conservarán en las notas del proyecto con un enlace a la conversación correspondiente.

## Incorporar documentación

Mantener las fuentes originales identificadas y los resúmenes enlazados a ellas. La fecha más reciente no demuestra por sí sola que un documento describa el montaje actual. Antes de publicar nuevos lotes, revisar su contenido y que puedan compartirse públicamente.
