# DEC-0010 · Pantallas de desarrollo y de usuario final

Armando solicita el 15-10 corregir los tres hallazgos de presentación y aclara que se trabaja en la fase de desarrollador; las pantallas para usuario final quedan pendientes para cuando esté terminado el proyecto.

Se mantiene ahora la interfaz de diagnóstico del frontal y su adaptación al banco: versiones, solicitado/recibido/aplicado, causas, CAN, SD y datos desconocidos explícitos. Se corrigen mensajes engañosos u ocultos durante esta fase. [ENS-0018](../../06_TRABAJO/ensayos/ENS-0018_mejoras_pantalla_desarrollo.md) aplica F01–F03 sin comenzar el rediseño final.

La interfaz de usuario final es una entrega pendiente de cierre: seleccionar información necesaria para conducción, navegación/avisos, legibilidad y táctil sobre el hardware validado. Sus requisitos concretos y aceptación se definirán entonces; no se declara diseñada, instalada ni terminada por las pruebas del banco.

La decisión se incorpora a [AGENTS.md](../../AGENTS.md) y [TAREAS](../../06_TRABAJO/TAREAS.md) para conservar el alcance entre sesiones. No cambia el protocolo CAN, la configuración física ni los requisitos de validación antes de instalar.
