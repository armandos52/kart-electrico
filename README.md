# Kart eléctrico

Documentación, evolución y seguimiento de un proyecto de kart eléctrico con historia desde 2008. Este repositorio permite compartir el trabajo con profesores y recibir observaciones vinculadas a documentos y cambios concretos.

**Estado local:** entrega de los profesores organizada, con 42 documentos catalogados y texto extraído de 1.007 páginas PDF. La lectura técnica exhaustiva sigue el [plan por lotes](06_TRABAJO/PLAN_DE_LECTURA.md). Los originales de esta recepción permanecen locales; la versión pública se actualizará al preparar su publicación.

## Para profesores y revisores

Se puede leer el repositorio público desde el navegador. Para participar, iniciar sesión en GitHub:

- **[Discussions](https://github.com/armandos52/kart-electrico/discussions):** preguntas, orientación general y debate de ideas.
- **[Issues](https://github.com/armandos52/kart-electrico/issues/new/choose):** observaciones concretas, errores o mejoras. Hay una plantilla de revisión académica.
- **Pull requests:** propuestas de cambios y revisión de las líneas modificadas antes de incorporarlas.

Al comentar, indicar el documento, su página o sección y, cuando se conozca, la configuración del kart. Consultar [cómo contribuir](CONTRIBUTING.md).

## Trabajo local y publicación

La carpeta del proyecto puede abrirse como bóveda de Obsidian. Los enlaces Markdown también funcionan en GitHub.

Guardar en Obsidian modifica la copia local. Git registra una versión mediante un commit; un push publica esa versión en GitHub. No hay sincronización automática configurada. Para trabajos que requieran revisión previa, se usará una rama y una pull request.

El archivo histórico se incorporará por lotes, conservando procedencia, páginas, configuraciones y distinción entre hechos e hipótesis. Los datos personales y el material que no pueda compartirse públicamente deben permanecer fuera de los archivos publicados.
