# Fuentes conservadas y alcance de la publicación

La entrega académica del 13-10-2026 publica el trabajo de continuación: documentación, fichas, código de trabajo, procedimientos, registros seleccionados, capturas y fotografías del kart seleccionadas para la revisión.

Los enlaces rotulados **«solo local»** identifican archivos de la copia de trabajo que no se distribuyen en este repositorio. En GitHub esos destinos no se podrán abrir. Se mantienen sus rutas para quienes disponen de la entrega original, y sus nombres/hashes en el [catálogo](../03_CATALOGO/INDICE_DOCUMENTOS.md) y el [inventario](../03_CATALOGO/inventario_archivos.csv). Para revisar una fuente concreta con los profesores, indicar su DOC, página/hoja y hash y consultar la copia de la entrega académica.

Clonar este repositorio basta para leer las notas, ejecutar el panel y las pruebas de lógica. Para compilar el STM32 completo se necesita la entrega histórica y restaurar las dependencias verificadas como explica su [guía](../07_DESARROLLO/firmware/stm32_frontal/README_ROBUSTEZ.md). La compilación no requiere ni autoriza grabar una placa.

Los originales no se han borrado ni reescrito. No se declara una revisión integral de fuentes ni una copia independiente de todo el archivo. La publicación tampoco cambia la autoría o licencia de materiales heredados y bibliotecas.
